\section{引言}

\subsection{研究背景}

Web 已由以静态页面和超链接为主的信息空间，发展为承载新闻、知识、商品、社交内容及音视频资源的综合信息基础设施。其内容具有规模庞大、持续更新、来源异构和质量不一等特点，而用户查询通常短小、含义模糊，真实信息需求也未必能够由关键词直接表达。因此，搜索系统需要在有限响应时间内完成内容获取与索引、候选召回和相关性排序，并从海量信息中识别可信且真正有用的结果。如何同时保证检索效率、语义相关性与结果可靠性，始终是现代 Web 信息获取的核心问题。

大语言模型的发展进一步改变了用户获取 Web 信息的方式。与返回链接列表的传统搜索不同，生成式系统能够综合上下文，以自然语言直接回答问题，但模型参数中存储的知识具有更新滞后、来源不透明等局限，也可能生成缺乏事实依据的内容。检索增强生成（Retrieval-Augmented Generation, RAG）将外部检索结果引入生成过程，使模型能够利用可更新的非参数化知识，并为回答提供证据基础\parencite{lewis2020rag}。这一变化使检索的目标由寻找“与查询相关的文档”，进一步扩展为寻找“足以支撑回答的证据”。与此同时，检索对象也由文本扩展到图像、音频和视频，系统需要处理跨模态语义对齐、细粒度证据定位以及检索结果与生成模型之间的协同问题。

WWW 2026 将搜索、排序、检索增强生成、多模态检索和智能体搜索等议题纳入“搜索与检索增强人工智能”研究方向\parencite{www2026track}，反映出 Web 搜索正在由相对独立的信息检索模块，演变为生成式人工智能获取外部知识和执行复杂任务的基础能力。在这一背景下，梳理搜索技术的演进逻辑，并结合具体论文考察多模态 RAG 的能力边界，有助于理解现代 Web 系统如何从信息匹配走向证据组织与答案生成。

\subsection{研究问题}

基于上述背景，本文围绕以下三个相互衔接的问题展开：

\begin{enumerate}[label=（\arabic*）]
  \item Web 搜索如何从关键词匹配、倒排索引、候选召回和相关性排序，发展到稠密检索、神经排序与 RAG？这一演进过程中，不同技术分别解决了哪些问题，又引入了哪些新的局限？
  \item WWW 2026 搜索与检索增强人工智能相关研究呈现出哪些重点？这些工作如何体现研究目标由文档相关性向生成可靠性、系统效率、多模态证据与智能体决策的扩展？
  \item 代表性论文 CFVBench 如何评价细粒度视频多模态 RAG？该研究揭示了现有系统在视频检索、短暂视觉信息捕捉和跨模态证据整合方面的哪些能力与不足？
\end{enumerate}

三个问题构成由技术脉络、研究现状到具体案例的分析路径。第二章沿关键词检索、索引、召回与排序、稠密检索、神经排序和 RAG 的顺序展开研究综述，并归纳 WWW 2026 的主要研究重点；第三章以 CFVBench 为对象，分析其研究动机、数据与任务设计、评价框架、改进方法及实验结论；第四章总结全文，并讨论检索增强人工智能进一步发展的关键方向。
